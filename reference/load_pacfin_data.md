# Function to load in a PacFIN Rdata file.

The function expects the Rdata file to have a name of bds.pacfin.

## Usage

``` r
load_pacfin_data(dir, file_name)
```

## Arguments

- dir:

  Directory location to save the cleaned data frame

- file_name:

  PacFIN Rdata file to be loaded
