# Clean pulled PacFIN data

Clean pulled PacFIN data

## Usage

``` r
clean_pacfin_comps(bds_pacfin, species, spid_key, year = 1980)
```

## Arguments

- bds_pacfin:

  Dataframe of PacFIN data

- species:

  list of species name to retain

- spid_key:

  csv file with PacFIN species codes and full species name

- year:

  Integer to filter PacFIN data to retain all data from this year and
  beyond
