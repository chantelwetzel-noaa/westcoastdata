# Clean pulled PacFIN data

Clean pulled PacFIN data

## Usage

``` r
clean_pacfin_comps(dir, bds_pacfin, species, spid_key, year = 1980)
```

## Arguments

- dir:

  Directory location to save the cleaned data frame

- bds_pacfin:

  Dataframe of PacFIN data

- species:

  add definition

- spid_key:

  add definition

- year:

  Integer to filter PacFIN data to retain all data from this year and
  beyond
